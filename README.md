## 脚本用法

```bash
export AMAP_KEY=你的高德Web服务Key   # 高德开放平台免费申请，Key 请勿提交到仓库
python3 amap_planner.py --city 成都 --route 春熙路 成都东站
python3 amap_planner.py --city 重庆 --route 解放碑 李子坝轻轨站
python3 amap_planner.py --itinerary   # 一键输出全部路段
```
